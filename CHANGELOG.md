# Changelog

All notable GitBan:Flow template changes should be recorded here.

This project treats process as code: workflow changes, labels, docs, and automation deserve the same visible history as product changes.

## 0.1.0 - Template Bootstrap

- Added GitHub Projects v2 automation for issue, label, pull request, review, merge, and close events.
- Added reusable `GitBan Status` board flow: `Backlog`, `Hotfix`, `In Progress`, `Blocked`, `In Review`, `Done`, and `Merge Log`.
- Added reusable smoke-test issue pattern and reset workflow.
- Added issue templates, pull request template, label bootstrap workflow, and testing labels.
- Added CLI helper scripts for starting issues, opening PRs, marking blocked work, and marking hotfixes.
- Added placeholder CI check names: `ci / lint`, `ci / test`, and `ci / build`.
- Added setup, operating, security, agent, CLI, smoke-test, and testing strategy docs.
- Relaxed branch naming from a hard gate to optional guidance.
