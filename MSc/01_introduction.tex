\section{Objectives}
\begin{itemize}
  \item Review relevant literature on curvature preference, organic design, procedural generation, and web UI implementation.
  \item Identify technical requirements for generating reusable curvilinear UI components.
  \item Design and implement a prototype API for procedural generation of curvilinear UI elements.
  \item Evaluate the prototype in terms of perceived ease of use, perceived usefulness, and technical suitability.
  \item Reflect on the extent to which the prototype addresses the identified research and technology gap.
\end{itemize}

\section{Research Questions}
\begin{itemize}
  \item How can a procedural API be designed to generate reusable curvilinear UI components for conventional web layouts?
  \item What parameters are required to generate visually coherent curvilinear UI elements?
  \item How can generated curvilinear elements be integrated with existing CSS-based layout and component systems?
  \item What technical constraints affect responsiveness, consistency, and usability?
  \item How do potential users perceive the ease of use and usefulness of the prototype API?
\end{itemize}
