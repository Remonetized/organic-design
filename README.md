# Organic Design API Prototype

Prototype artefact for procedural generation of curvilinear user interface components.

## Run

Open the project through XAMPP:

```text
http://localhost/organic-design/
```

The current reset point is a plain HTML/CSS/JavaScript prototype.

## Current Scope

- Recovered honours JavaScript adapted into a static root page.
- Curvilinear and jagged div generation using `clip-path` and `shape-outside`.
- Copyable HTML, CSS, and SASS output panels.
- Earlier React/Vite and recovered source material kept in `_archive/`.
