# Organic Design API Prototype

Prototype artefact for procedural generation of curvilinear user interface components.

## Run

```powershell
npm install
npm run dev
```

## Current Scope

- Vite + React prototype.
- Seeded SVG boundary generation.
- Adjustable intensity, smoothness, points, dimensions, and active edges.
- Demo outputs for card, container, and divider use cases.
- Copyable SVG and API usage snippets.
